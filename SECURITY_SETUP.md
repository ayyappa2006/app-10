## GitHub Actions Pipeline

The pipeline runs automatically on **every push and pull request**.

### Jobs in the Pipeline

| Job | Tool | What It Does |
|-----|------|-------------|
| `detect-stack` | Custom script | Detects PHP, Node.js, Python, Java |
| `sast-semgrep` | Semgrep | Static analysis for PHP/JS security issues |
| `secret-detection` | Gitleaks | Scans for secrets, API keys, credentials in code |
| `dependency-scan` | Trivy | Scans filesystem for vulnerable packages and CVEs |
| `php-security-analysis` | Custom + PHPCS | PHP-specific pattern scanning (30+ security patterns) |
| `dast-api-testing` | Custom Python | Live API testing (only runs if API URL is provided) |
| `generate-reports` | Python/openpyxl | Generates all Markdown + Excel reports |
| `security-gate` | Custom | Fails CI on CRITICAL vulnerabilities |

### Triggering the Workflow

**Automatic (on push/PR):**
```bash
git push origin main  # Pipeline runs automatically
```

**Manual with live API URL:**
1. Go to GitHub → Actions → `Comprehensive Security Review`
2. Click **"Run workflow"**
3. Enter your API base URL (e.g., `http://your-server.com`)
4. Click **"Run workflow"**

**Failure behavior:** The pipeline **fails** when Critical vulnerabilities are found, blocking merges.

## Downloading Reports

After the workflow runs:

1. Go to **GitHub → Actions**
2. Click the latest **"Comprehensive Security Review"** run
3. Scroll down to **Artifacts**
4. Download:
   - **`Security-Review-Reports`** — Full report bundle (zip)
   - **`semgrep-results`** — Semgrep SAST output
   - **`trivy-results`** — Trivy dependency scan
   - **`php-security-results`** — PHP custom scan
   - **`gitleaks-results`** — Secret detection results

## Running Security Tools Locally

### Semgrep
```bash
pip install semgrep
semgrep --config=p/php --config=p/owasp-top-ten .
```

### Gitleaks (secret detection)
```bash
# Windows
winget install gitleaks
gitleaks detect --source=. --report-format=json --report-path=gitleaks.json

# Linux/Mac
brew install gitleaks
gitleaks detect --source=.
```

### Trivy
```bash
# Windows
winget install aquasecurity.trivy
trivy fs --severity HIGH,CRITICAL .

# Linux
wget https://github.com/aquasecurity/trivy/releases/download/v0.48.0/trivy_0.48.0_Linux-64bit.tar.gz
tar -xzf trivy*.tar.gz && ./trivy fs --severity HIGH,CRITICAL .
```

## Remediation Priority

Fix these **NOW** before any production deployment:

```
Week 1 — CRITICAL (Stop Everything)
├── Implement PHP sessions or JWT authentication
├── Add OTP to password reset flow  
└── Convert all queries to PDO prepared statements

Week 2 — HIGH (Fix Urgently)
├── Add ownership checks to delete/update endpoints
├── Restrict CORS to known domains
├── Move DB credentials to .env
├── Add security headers
├── Implement rate limiting
├── Fix file upload security
└── Remove DB errors from responses

Week 3 — MEDIUM/LOW
├── Password strength validation
├── Email format validation
├── CSRF tokens
└── Generic error messages
```
